# Andrew Ciervo — portfolio

**Live:** https://datbluepony.github.io/

What I've built, how it works, and what broke along the way: a home camera-AI system on a Raspberry Pi, a Tesla-browser road app, a construction photo pipeline, a 240SX wiper controller board, a job-search engine, and more.

Plain HTML, CSS and JavaScript. No framework, no build step. Push to `main` and it's live.

```
index.html            the page
assets/css/site.css   styles (same palette and type as the Cape House Hub)
assets/js/site.js     nav, staged intro, reveals, filters, Hub screen switcher, lightbox
assets/js/demos.js    interactive pieces: pipeline player, accuracy chart, fog of war,
                      route planner, job-score calculator, risk bars, 3D dock viewer
assets/img, vid       screenshots and clips captured from the real apps
assets/models         the charging dock's print file (binary STL)
play/house-builder    the browser game, playable
play/dash-led         the LED strip simulator, playable
```

Screenshots of private apps were taken on my own machines. Visitors' names and a delivery driver's face are changed or blurred. Blockchain Surfer and TeslaDash were recorded against sample data feeds, not live accounts.
